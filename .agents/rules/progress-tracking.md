# Agent Progress Tracking Rule

## Automatic Progress Updates
- Whenever an agent completes a significant task, feature, architectural modification, bug fix, or milestone, the agent **must automatically update [`progress.md`](../../progress.md)** at the root of the workspace.
- Specific update requirements:
  1. **System Health Matrix:** Update component status or last verified date if modified.
  2. **Milestones:** Check off completed items or add new completed feature entries.
  3. **Activity Log:** Add a new entry to the `Activity & Agent Update Log` table detailing the date, description of work accomplished, and status.
- Keep `progress.md` accurate, structured, and free of sensitive private credentials or passwords.
