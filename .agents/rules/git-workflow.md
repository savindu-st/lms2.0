# Git Workflow & Commit Rules

## Strict Commit Constraint
- **NEVER execute `git commit` or `git push` autonomously.**
- Do NOT commit changes unless the user **explicitly** instructs you to commit in their prompt (e.g., "commit the changes", "do the commit", "run git commit").
- When finishing tasks, leave modifications in the working tree or staged, summarize what was changed, and ask the user if they would like to commit.
- Even if a plan or workflow finishes, do not commit as a clean-up step unless explicit user approval or instruction is given.
